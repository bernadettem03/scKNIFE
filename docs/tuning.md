# Parameter selection

Follow the dedicated {doc}`tutorials/10000-validation` page for optional rank sensitivity and projection, with code, plots and interpretation together.

The main {doc}`tutorial-10000` uses a predeclared rank of 16 and compares ranks 8, 16 and 24 in an exploratory held-out reconstruction diagnostic.

See the rank sensitivity and held-out projection section of {doc}`tutorial-10000` for the executed diagnostic. It partitions the selected 10,000 cells into training and held-out sets; the main biological analysis fits all 10,000. These are exploratory checks, not evidence of a unique optimal biological rank.
